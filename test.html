🛠️ CORS 우회 방법:

방법 1: CORS 프록시 서버 (추천)
현재 사용 중: https://api.allorigins.win/raw?url=

별도 설정 없이 바로 사용 가능합니다.

방법 2: 브라우저 확장 프로그램
  1. Chrome 웹스토어에서 "CORS Unblock" 또는 "CORS Everywhere" 설치
  2. 확장 프로그램 활성화
  3. 페이지 새로고침 후 사용
방법 3: Chrome 플래그로 실행
  1. Chrome 완전 종료
  2. 터미널/명령 프롬프트에서 실행:
    3. Windows: chrome.exe --user-data-dir="C:/Chrome dev session" --disable-web-security
    macOS: open -n -a /Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --args --user-data-dir="/tmp/chrome_dev_sess" --disable-web-security
    Linux: google-chrome --user-data-dir="/tmp/chrome_dev_sess" --disable-web-security
